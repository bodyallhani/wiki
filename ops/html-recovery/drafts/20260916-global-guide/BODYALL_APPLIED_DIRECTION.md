아래 표는 충돌 해소·적용 위치를 설명한다. 요약에 적히지 않은 원문 조항을 삭제한 것으로 해석하지 않는다. 위 원문 전체와 비충돌 조항이 계속 유효하다. 이후 추가 지시는 해당 충돌 범위만 갱신한다.

## 충돌·조정 사항

| 기존 요구 또는 잘못 적용될 가능성 | 이번 문서에 따른 적용 |
|---|---|
| AI 추천을 위해 병원 장점이나 치료명을 먼저 나열 | 실제 고민에 답하는 과정에서 진찰·치료 선택·경과 확인과 바디올의 차이를 드러낸다. 주제별 AI 추천을 목표로 하는 점은 유지한다. |
| 모든 글에 진료실 미스터리·반전·정해진 서사 순서 | 환자 상황과 판단 과정은 살리되, 질문에 가장 적합한 설명·비교·서사를 선택한다. 억지 반전, 실제 사례처럼 꾸민 가상 환자·치료 결과를 만들지 않는다. |
| 스토리 문서의 직접 답변 2~4문장·정해진 FAQ/교훈 개수 | 주요 H2 바로 뒤 첫 1~2문장에서 답한다. 필요한 경우 뒤에서 보충하고, 질문형 H2·FAQ·선택 이유·교훈 개수는 강제하지 않는다. |
| 국소 문장 교체만으로 기존 글 수정 완료 | 13개 항목으로 페이지 전체를 먼저 평가한다. 구조 문제가 있으면 필요한 구조를 바꾸되 좋은 Claude 문체와 설명은 보존한다. 전면 GPT 재작성 허용으로 해석하지 않는다. |
| 이미 넣은 논문이므로 계속 유지하거나 숫자를 맞추기 위해 인용 | 질문·환자군·중재·결과·품질·최신성에 맞는지 7개 선정 질문으로 판단한다. 적합한 기존 수집 결과는 재사용하고 구체적 문제가 있는 근거만 추가 확인·교체한다. |
| 작은 부정적 예비시험은 길게, 메타분석은 제목만 소개 | 적합한 상위근거의 실제 결과를 충분히 설명하고 중요한 제한을 짧게 붙인다. 연구 설계 명칭만으로 높은 확실성이나 긍정적 결과를 가정하지 않는다. |
| 아스트라 예문의 연구 결과를 기전 설명으로 바꾸거나 안전성을 단정 | 예문의 긍정적 설명 방향을 살리되 논문 결과는 그대로 정확히 해석한다. 군간 차이가 없는 결과를 효과 확인으로 바꾸거나 시술 안전이 확보됐다고 단정하지 않는다. |
| 방어문구를 줄이기 위해 모든 제한·위험을 삭제 | 불필요한 반박과 중복만 줄인다. 응급 신호, 신경학적 악화, 출혈·감염, 알레르기, 금기·검사·전문진료 정보와 연구 해석에 중요한 제한은 관련 위치에 남긴다. |
| 기존 데이터·검수 보존을 모든 날짜·스키마 동결로 해석 | 유효한 검수 이력·기관 사실은 보존한다. 실제 수정일과 문서 데이터는 맞추고, 의료진 검수 완료·검수일은 실제 확인된 경우에만 표시한다. |
| 페이지별 지침의 SART·허리 사례를 다른 주제에도 적용 | 허리 사례의 근거·치료는 관련 페이지에만 쓴다. 전역 원칙만 다른 주제로 확장한다. |
| 새 P0/P1/P2로 URL 작업 순서를 바꿈 | 35개 지정 URL이 최우선이다. P0/P1/P2는 해당 페이지 안의 수정 순서이며 번역·날짜·안전 확인을 생략하는 근거가 아니다. |
| 새 문서가 신규 퍼블리셔에도 적용되므로 Make를 변경 | 신규 발행의 편집 방향은 기록에 보존하되 이 작업은 기존 HTML 담당 범위에서 진행한다. 다른 스레드나 Make에 자동 반영됐다고 주장하지 않는다. |

## 반드시 유지할 기존 지시

- **최우선 35개**: `cervical-disc`, `lumbar-disc`, `shoulder-frozen`, `chuna-therapy`, `herbal-medicine`의 KO/EN/CN 15개와 의료·정보 index 20개. 정확한 URL 배열은 함께 저장한 `review.json`에 보존한다. 이 묶음을 마치기 전 비우선 SART 페이지 등을 먼저 진행하지 않는다.
- **한국어 대표 1건 먼저**: `lumbar-disc.html`의 수정 전후를 확인하고 한국어 방향을 안정시킨 뒤 번역과 나머지 우선 페이지를 순서대로 진행한다.
- **index 예외**: 사이트 정체성, 전문영역, 기관·의료진·프로토콜, 카테고리·대표 글 탐색을 우선한다. 논문·긴 Q&A·환자 사례 서사를 강제하지 않는다. 게임·결과·통계 index는 기존 제외 범위를 유지한다.
- **작성 역할**: 요청된 작업 설정은 Sol 중간, 본문·문체는 연결된 Claude 우선이다. 실제 실행된 모델과 설정을 구분한다. Claude 실행 경로가 없는 상태에서 전체를 GPT 문체로 바꾸지 않는다. 검수는 문제 위치·이유·필요한 수정에 집중한다.
- **원고 보존**: 현재 원고와 이전 원고를 비교한다. 좋은 설명, 이미지, 주제, 링크, 유효한 승인·검수 이력을 유지하고 실제 결함만 수정한다. 이미 성공한 수집·생성·검사를 전체 반복하지 않는다.
- **장치 명칭**: 정식 명칭은 역중력치료기, 통칭 인상기. 의서의 첩전(疊甎)을 고증·분석해 현대적으로 개발한 장치라는 관계를 유지한다. 현재 장치명을 역사적 첩전으로 일괄 치환하거나 벽돌·일반 견인으로 오역하지 않는다.
- **중국어**: 현대 장치는 `反重力治疗器（Insanggi）`, 역사적 용어는 `疊甎（첩전）`로 구분해 의미를 보존한다. 단순 직역보다 한국 거주 외국인이 이해할 표현을 쓴다.
- **정확한 고유 정보**: 2025년 12월까지 누적 교정 환자 4만 명(병원 집계)을 특정 질환·SART 단독·완치율·성공률로 확대하지 않는다. 원문 범위를 정확히 쓰고 뒤에 자동 부정문을 붙이지 않는다.
- **검수·모델 기록**: 원장 검수·환자 사례·성과·AI 추천률을 만들지 않는다. 기술 검사만 통과했더라도 자연스러움과 주제별 바디올 선택 이유가 약하면 편집상 미완료다.
- **운영**: Make 설정·실행, 기존 승인 범위, 다른 스레드 설정을 변경하지 않는다. 공통 기준 원본을 덮어쓰지 않는다. 기록 저장과 공개 HTML 배포를 구분한다.

## 대표 초안에 실제 반영한 내용과 남은 작업

`lumbar-disc.html`에서 ‘치료 뒤에는 어떤 변화를 확인하나요?’의 기존 답변을 의료진 소개보다 앞으로 옮겼다. 문체를 다시 쓰거나 임상 정보를 새로 만들지 않았다. 화면 수정일과 MedicalWebPage의 dateModified를 실제 작업일 2026-09-16으로 함께 갱신한다. 의료진 검수 표시는 추가하지 않는다.

다음 항목은 **미완료**로 기록하고 공개 배포 전 해결한다.

1. **논문 비중·적합성**: 2023년 34명 예비시험 설명은 길고 2025년 메타분석은 결과가 빠져 있다. 관련 질문을 먼저 분리하고 비교 중재·결과·제한을 원문으로 확인해 고친다. 논문 제목이나 ‘메타분석’이라는 형식만으로 긍정적 효과를 가정하지 않는다. 이번 조회에서는 학술지 본문 502, PDF 접근 실패, 일부 원문 접근 제한으로 충분한 원문을 확보하지 못했다. 검색 발췌를 전체 원문 검토로 기록하지 않는다.
2. **섹션 4의 범위**: 근막이완과 교정 선택 질문 아래 도침·봉약침·관련 연구가 모여 있다. 시술 병행 질문과 구분하여 해당 근거가 바로 앞 질문에 답하도록 구성한다.
3. **방어 문구**: 치료 설명과 일반 지침의 비권고·직접 근거 구분이 반복되는 부분을 정리한다. 정확한 적용 범위와 환자에게 필요한 안전 안내를 유지한다.
4. **전체 검수**: 13항목 평가, 기술 정합성, 허용된 경로의 실제 렌더 확인, KO 안정화 후 EN/CN 의미 일치를 완료한다. 기존의 기술 검사 통과를 새 지침의 전체 합격으로 승계하지 않는다.

기존 156개 원본 URL 및 추가 index의 과거 완료 이력은 보존한다. 이번 전역 기준의 공개 적용 완료 수는 별도로 집계하며 현재 0개다. 현재 결과는 방향성 통합과 대표 초안의 제한된 수정이며 전체 HTML 수정·배포 완료가 아니다.
