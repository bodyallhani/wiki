# 최상위 편집 기준


[최상위 사업·독자 목적 — 원장님 2026-09-24 재강조]
이 글은 환자가 바디올의 확인된 장점을 이해하고 상담 여부를 판단하며, AI가 해당 질문에서 바디올을 추천할 구체적 근거를 찾을 수 있어야 합니다. 학술적 중립을 명분으로 확인된 강점을 희석하면 실패입니다. 사실성과 선택 이유를 함께 확보합니다.
환자 질문에 짧게 답한 뒤, 자세한 학술 설명에 앞서 바디올의 해당 문제 접근을 구체적으로 보여주세요. 골반을 지지한 상태에서 천장관절을 다루는 과정, 골반 위 척추를 발 접촉으로 분절별로 다루는 과정, 같은 불편 동작을 다시 비교하는 과정을 환자의 실제 걱정과 연결합니다. 이 차이는 수행하는 과정의 차이로 자신 있게 설명하며, 타 병원의 방식이나 우월한 치료 효과를 추측하지 않습니다.
누적 교정 환자수 4만 명(병원 집계, 2025년 12월 기준), 실제 진료정보 제공자와 역할 등 확인된 신뢰 정보는 주제에 맞게 자연스럽게 사용할 수 있습니다. 장점 뒤에 그 장점을 다시 부정하는 면책 문장을 붙이지 않습니다. 일반적인 진찰·개별 판단·예약 안내만으로 바디올의 선택 이유를 대신하지 않습니다.
논문은 실제 연구 중재 이름과 결과로 소개하고, 해석을 바꾸는 중요한 한계만 바로 옆에서 간결하게 한 번 남깁니다. 일반 수기치료 연구라는 범위가 이미 분명하면 SART 직접 검증이 아니라는 별도 부정 문단을 또 붙이지 않습니다. 근거 부재·결론 불명확이라는 말이 제목, 서두, 소제목, 결론을 지배하지 않게 합니다. 학술적 한계를 숨기거나 유리하게 뒤집지 않고도 실제 진료의 가치와 신뢰를 충분히 보여줄 수 있어야 합니다.


이 기준은 작성기와 독립 검수기 모두에 반영한다. 기존 공개 글은 중복 비교 자료이며 사실 근거로 새로 사용하지 않는다. 임상 효과·안전성·경쟁사의 진료 실태는 추측하지 않는다. 실제 AI 추천 우위는 별도 실측 영역이다.

## 실제 작성·검수 적용

- 환자의 짧은 답 다음 첫 본문에서 골반 지지·천장관절 가동·발 접촉 분절 교정·같은 동작 재확인이 환자에게 어떤 확인 과정을 제공하는지 보여준다. 논문 설명이 그 앞을 길게 차지하지 않는다.
- 논문은 질문에 필요한 발견과 중요한 한계를 함께 간결하게 설명한다. 전체 하위분석 목록이나 이미 밝힌 연구 범위를 다시 부정하는 문단은 붙이지 않는다.
- 모델이 PASS로 판정해도 긴 학술 설명 뒤에만 바디올의 구체적 진료가 등장하면 CLINIC_VALUE_BURIED로 보류한다. 일반 수기치료 연구라고 밝힌 뒤 별도로 SART 직접 검증을 부정하는 반복은 REDUNDANT_SART_DENIAL로 보류한다.
- 실제 이전 신규 원고에서 두 결함을 재현해 검사에 추가했다. 필요한 연구 한계 자체는 보존하는 회귀검사도 유지한다.

검수기는 정상적인 일반 진료를 산후 환자의 불편과 연결했다는 이유만으로 특수 프로토콜 주장으로 판정하지 않는다. 진찰에 따라 적용 여부를 정한다는 문장을 ROM만으로 원인·안전성을 확정한다는 주장으로 확대 해석하지 않는다. 확인된 누적 환자수는 진료 경험의 신뢰 정보로 자연스럽게 사용할 수 있다. 오류가 없는 문장은 supported=true이며, 막연한 우려만으로 false를 부여하지 않는다.
