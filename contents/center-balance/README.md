# 중심잡아! — Center Club

`https://wiki.body-all.co.kr/contents/center-balance/`에 게시되는 설치 없는 3D 물리 웹게임입니다.

## 구성

- `index.html`, `style.css`: 모바일 우선 게임 UI
- `engine.mjs`: 고정 시간 간격의 결정적 중심잡기 시뮬레이션
- `app.mjs`: Three.js 3D 장면, Cannon-es 실패 래그돌, 조작, 기록, 공유
- Three.js와 Cannon-es는 버전을 고정한 jsDelivr CDN 모듈을 사용합니다. 별도 빌드 서버는 필요하지 않습니다.
- `assets/`: 대문용 캐릭터와 공유 이미지
- `test-engine.mjs`: 결정성, 시드 검증, 리플레이 인코딩 검사

## 플레이와 경쟁

- 캐릭터가 쏠리는 쪽 화면을 눌러 발판 자체를 기울이고, 공·돌풍·발판 충격을 20초 동안 버팁니다.
- 위험 구간에서 복귀하면 회복 콤보와 보너스 점수를 얻습니다.
- 오늘의 기본 패턴은 한국 날짜를 기준으로 모든 이용자에게 같습니다.
- 결과의 도전장은 패턴 시드, 기록, 압축된 조작 리플레이를 URL에 담습니다. 개인정보·건강정보·위치정보를 넣지 않습니다.
- 친구 링크로 접속하면 같은 흔들림과 목표 기록이 표시됩니다.
- 공개 세계 랭킹은 없습니다. 최고기록과 시도 횟수는 해당 브라우저의 localStorage에만 저장합니다.

## 브랜드와 의료 안전

첫 화면은 Center Club 게임 브랜드를 중심으로 표시하고 `A tiny game by Bodyall`을 작게 표기합니다. 플레이 결과에서 이용자가 선택할 수 있는 제작 이야기와 바디올 척추교정 페이지 링크를 제공합니다.

게임 기록을 자세, 균형 능력, 척추 상태, 질환 또는 치료 필요성과 연결하지 않습니다. 진료비 할인, 방문 보상, 리뷰·저장 보상은 포함하지 않았습니다. 쿠폰이나 기타 경제적 혜택은 의료광고 및 환자 유인 관련 별도 검토 전에는 연결하지 않습니다.

## 검증

```bash
node --check app.mjs
node --check engine.mjs
node test-engine.mjs
node test-static.mjs
```

ES 모듈과 WebGL을 사용하므로 로컬 파일로 직접 열지 말고 정적 HTTP 서버에서 확인합니다.
