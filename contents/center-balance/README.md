# 말랑 중심탑 — Mallow Tower

`https://wiki.body-all.co.kr/contents/center-balance/`에 게시되는 설치 없는 원탭 3D 물리 웹게임입니다.

## 핵심 플레이

- 좌우로 움직이는 말랑 분절이 원하는 위치에 왔을 때 화면 어디든 한 번 탭해 쌓습니다.
- 탑이 기울면 캐릭터가 반대로 몸을 틀어 버티고, 형광 근육 밴드와 HUD의 부하가 실시간으로 증가합니다.
- 다음 분절을 반대쪽에 놓아 무게중심을 회복하면 근육 부하가 줄고 회복 보너스를 얻습니다.
- 분절을 놓치거나 누적 부하가 한계에 닿으면 Cannon-es 물리 붕괴가 시작됩니다.
- 처음 3층은 중심 부근의 입력을 자동 보정해 첫 플레이 진입 장벽을 낮췄습니다.

## 구성

- `index.html`, `style.css`: 모바일 우선 게임 UI와 보상작용 안내
- `engine.mjs`: 고정 시간 간격의 결정적 탑·중심·누적 부하 시뮬레이션
- `app.mjs`: Three.js 3D 장면, 근육 부하 시각화, Cannon-es 붕괴, 기록과 공유
- `assets/`: 대문용 마스코트와 공유 이미지
- `test-engine.mjs`: 결정성, 장기 플레이, 과부하와 회복, 실패 판정 검사
- `test-static.mjs`: DOM, 정적 자산, 의료 안전 문구 검사

Three.js와 Cannon-es는 버전을 고정한 jsDelivr CDN 모듈을 사용하며 별도 빌드 서버는 필요하지 않습니다.

## 경쟁과 기록

- 한국 날짜 기준 오늘의 경사 시드는 모든 이용자에게 같습니다.
- 최고 층수, 점수, 정확한 정렬과 중심 회복 누계는 해당 브라우저의 localStorage에만 저장합니다.
- 도전 링크에는 시드, 층수와 점수만 포함하며 개인정보·건강정보·위치정보를 포함하지 않습니다.
- 친구 링크로 접속하면 같은 시작 경사와 목표 기록이 표시됩니다.

## 메시지와 의료 안전

핵심 문구는 “몸이 버틴다고, 중심이 맞는 것은 아닙니다.”입니다. 기울어진 구조에서 캐릭터가 반대로 몸을 틀어 버티고, 구조의 중심이 회복되면 부하가 줄어드는 과정을 게임적으로 표현합니다.

보상작용은 재미를 위해 단순화한 은유입니다. 게임 기록과 근육 부하 수치는 자세, 척추 상태, 건강 상태, 질환 또는 치료 필요성을 측정하지 않습니다. 진료비 할인, 치료 쿠폰, 방문·리뷰 보상은 포함하지 않습니다.

## 검증

```bash
node --check app.mjs
node --check engine.mjs
node test-engine.mjs
node test-static.mjs
```

ES 모듈과 WebGL을 사용하므로 로컬 파일로 직접 열지 말고 정적 HTTP 서버에서 확인합니다.
