## 확장·미확인 범위

현재 대사는 규칙 기반이며 추임새는 사전 생성한 고정 음원 파일을 재생한다. 전체 게임이 실행 중 얼굴을 다시 생성하지 않는다. 결과별 링크 미리보기는 13개 정적 페이지로 제공하며, 개별 답변 조합마다 서버에서 카드를 생성하지 않는다. 실제 성향 문장은 공유 문구·이미지·URL fragment를 읽는 결과 화면에 반영한다. GA4 게임 이용통계는 최신 작업에서 연결했다. 내원 전환 측정은 연결하지 않았다. 실제 재미와 브랜드 기억은 공개 후 사용자 반응으로 평가한다.

기획서와 완성 자산을 기준으로 이어갈 수 있으며, 이미지 생성 프롬프트는 ARTWORK.json에 기록돼 있다. 불필요하게 전체 이미지를 다시 생성하지 않는다.

## 2026-09-11 — 실제 전생 결과 공유와 친구 참여

- 사용자 요구: 공통 테스트 소개가 아니라 ‘나는 전생에 손권 — 어떤 사람. 너는 누구였어?’처럼 자기 결과와 호기심을 공유해야 함.
- 원인: 기존 링크는 공통 index.html의 ?r= 결과 값만 달랐고, 정적 OG 제목·설명은 공통 소개였음. 공유 payload의 제목도 공통이며 이미지와 텍스트·URL을 동시에 보냈음.
- 변경: 일반 인물12종+말1종의 result/<id>/index.html. 이름·별칭·대표 성향·참여 유도 제목·해당 인물의 기존 초상화를 정적 OG/X 필드로 제공. 기존 도트 초상화의 해당 타일을 그대로 JPEG로 내보내며 새로 그림을 생성하지 않음.
