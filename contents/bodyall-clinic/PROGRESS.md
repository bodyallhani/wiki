## 후속 작업 시 먼저 할 일

1. GitHub main과 이 폴더의 실제 파일·최근 커밋을 확인한다. 다른 위키/자동화 스레드의 변경을 덮어쓰지 않는다.
2. 배포 완료 여부는 해당 커밋의 GitHub Pages workflow 상태로 확인한다. Blob 생성만으로 배포 완료라고 판단하지 않는다.
3. 최신 요청과 PLAN.md를 확인하고 기존 구현부터 수정한다. 새 프로젝트나 새 주소를 임의로 만들지 않는다.
4. 실제 브라우저·모바일 UI 시험은 아직 실행하지 않았다. 요청받으면 정면 거울의 크기, 손목 접촉, 선택지 터치, PNG 저장·메신저 공유를 우선 확인한다.

## 확장·미확인 범위

현재 대사는 규칙 기반이며 실제 음성 녹음은 없다. 전체 게임이 실행 중 얼굴을 다시 생성하지 않는다. 공유 이미지에는 개인화된 분석이 들어가지만 링크 미리보기까지 개인별로 생성하는 서버는 없다. 수집형 분석 도구와 내원 전환 측정은 연결하지 않았다. 실제 재미와 브랜드 기억은 공개 후 사용자 반응으로 평가한다.

기획서와 완성 자산을 기준으로 이어갈 수 있으며, 이미지 생성 프롬프트는 ARTWORK.json에 기록돼 있다. 불필요하게 전체 이미지를 다시 생성하지 않는다.
