Google Analytics에 로그인해 최근 7일 또는 30일을 선택하세요. 확정 보고서는 반영에 시간이 걸릴 수 있으며, 연결 직후에는 실시간 보고서에서 먼저 확인합니다.

실시간 수신 확인 ↗화타 이용통계 열기 ↗자동 통계 대시보드 ↗

분석 계정에 권한이 있는 사람만 원본 통계를 열 수 있습니다. 이 페이지는 비공개 통계를 자동으로 불러오거나 공개하지 않습니다.

CSV를 한글 요약으로 보기

  1. ‘화타 이용통계’ 보고서에서 기간을 선택합니다. 게임 이벤트만 자동으로 표시됩니다.
  2. 전체 게임 이벤트가 포함되도록 CSV로 내보냅니다.
  3. 아래에서 파일을 선택하면 완료·공유·인물별 통계를 바로 정리합니다.

아직 불러온 통계가 없습니다. 예시 수치를 실제 데이터처럼 표시하지 않습니다.

파일은 이 브라우저에서만 읽습니다. 업로드·서버 저장 없이 처리하며, 최신 수치는 새 CSV를 선택해야 반영됩니다.

배포처 구분 링크 만들기

게시할 곳에 맞는 링크를 쓰면 어떤 배포 경로에서 참여가 생기는지 구분하는 데 도움이 됩니다.

이 구분은 처음 배포한 링크의 표시입니다. 다른 앱으로 재전달될 수 있으므로 실제 사용 앱을 보증하지 않습니다.

숫자를 읽을 때

  • 통계 참여를 선택한 이용만 포함합니다. 전체 방문자나 고유한 사람 수가 아닙니다.
  • 다시하기는 새로운 플레이입니다. 한 플레이에서 반복한 공유·복사는 종류별 한 번만 집계합니다.
  • 공유 의도는 공유 시도 또는 링크 복사입니다. 카카오톡 발송·수신·읽음 완료를 의미하지 않습니다.
  • ‘공유 초대에서 시작’에는 본인이 공유 링크를 다시 연 경우도 포함될 수 있습니다.
  • 기간 경계에서 시작과 완료 날짜가 갈리거나 측정이 누락되면 비율에 오차가 생깁니다.
  • 게임 이용량과 SEO 성과는 구분합니다. 검색 노출·클릭은 Search Console에서 별도로 확인합니다.
