# 화타의 전생 진찰소 v2

Bodyall이 만든 삼국지 전생 성향 테스트. 제작자 표기는 로고와 `© Bodyall`로 통일합니다.

공개 경로: https://wiki.body-all.co.kr/contents/bodyall-clinic/

## 플레이와 결과

한의사로 돌아온 화타에게 손목을 맡기고 일상의 성향을 묻는 열 문항에 답합니다. 성별 질문은 없습니다. 답변에 따라 화타의 표정·자세가 바뀌고, 마지막에는 거울로 확대되며 전생이 드러납니다.

일반 결과는 기존 인물 12명과 익살스러운 신규 인물 10명입니다. 신규 인물은 맹획·동탁·원술·유선·장각·이각·형도영·예형·좌자·허저입니다. 전부 ‘잘 모르겠어요’일 때만 ‘하후돈이 타던 말’이 됩니다. 일부 질문에만 답해도 안개 결과나 보충 질문 없이 공유할 수 있는 결과가 나옵니다. 근거가 적으면 ‘적은 단서로 비친 전생’을 표시합니다.

매칭은 답변 일치 수·핵심 문항·고정 우선순위에 따른 결정적 규칙입니다. 실제 답변에 맞는 분석만 최대 두 문장 보여줍니다. 동일 답변의 결과는 바뀌지 않습니다. 일반 답변 1,048,576조합의 균등 가정 검증에서는 멋짐 53.085%, 웃김 46.915%입니다. 실제 참여자 분포나 심리 타당성을 입증하는 수치는 아닙니다. 자세한 패턴은 `PLAN-v2.md`, 검증 결과는 `MATCHING-v2.json`에 있습니다.

## 공유와 호환

공유 카드1080×1350에는 인물·별칭·실제 답변에 근거한 분석·참여 유도 문구·중앙정렬한 로고와 `© Bodyall`을 담습니다. 카드에 사이트 주소를 인쇄하지 않습니다.

공유는 결과별 제목·분석·초대 문구·전용 링크를 기기 공유창으로 전달하며, 지원하지 않으면 문구와 링크를 복사합니다. 이미지 저장도 가능합니다. 카카오톡 전용 SDK를 사용하지 않으므로 실제 메신저 발송·수신·읽음을 집계하거나 보증하지 않습니다.

v2 결과는 `result/v2/<id>/`를 사용합니다. URL의 fragment에는 공개된 분석 문장 번호 최대 두 개와 단서 부족 표시만 담습니다. 질문별 원문 답변은 공유하거나 서버에 보내지 않습니다. 링크 미리보기는 인물별 대표 설명이고, 실제 공유 문구와 친구가 연 화면은 받은 분석입니다.

기존 `data.js`, `engine.js`, `result/<id>/`, `shared-result.js`를 보존하여 이미 보낸 v1 링크의 문장 의미를 유지합니다. 옛 링크에서 새로 시작하면 현재 v2 질문을 받습니다. `scripts/build-share-pages.cjs`는 v1 전용이며 v2 개편 때 실행하지 않습니다.

## 주요 파일

- `data-v2.js` / `engine-v2.js`: 10문항·22인물·특별 결과·근거 분석·결정적 매칭·공유.
- `reactions-v2.js` / `actor.js`: 질문에 맞는 반응과 기존 눈 깜빡임·표정·호흡·자세.
- `app.js` / `card.js`: 진행·거울 공개·공유카드. 새 초상화 로딩이 시작 버튼을 막지 않습니다.
- `assets/portraits-v2/` / `ARTWORK-v2.json`: 신규 도트 초상화10종(합계 약0.9MB), 생성 지침·해시.
- `scripts/build-share-pages-v2.cjs` / `SHARING-v2.json`: v2 결과23종의 정적 미리보기와 초상화 내보내기.
- `stats/` / `ANALYTICS.md`: 기존판·개편판을 분리한 이용통계 조회와 한글 CSV 요약.

## 음원과 이용통계

원장님이 직접 청취 승인한 동일 녹음의 ‘음·아하·허허’ MP3 세 개와 오리지널 BGM을 유지합니다. 기기 기본 음성이나 새 화자 합성을 사용하지 않습니다. 첫 클릭에서 소리가 시작되고 음소거·페이지 가림·움직임 줄이기 설정을 따릅니다. 승인 원본 정보는 `AUDIO.json`에 있습니다.

답변은 현재 페이지 메모리에만 보관합니다. ‘통계 참여’를 선택한 경우에만 허용된 진행·공유 이벤트를 GA4로 보냅니다. v2 이벤트는 `huata_v2_`, 기존판은 `huata_` 접두사를 사용합니다. 원문 답변·분석 문장·개인식별정보는 전송하지 않습니다. 참여 여부는 localStorage, 참여 시 게임 경로 전용 분석 식별자는 쿠키에 보관합니다. 상세 안내는 `privacy.html`을 참고합니다.

## 실행과 검증

빌드 없이 정적 웹 서버 또는 GitHub Pages에서 실행합니다. 공유 이미지 제작 도구와 카드 테스트만 `@napi-rs/canvas`가 필요합니다.

검사: `node test-v2.cjs`, `node scripts/check-distribution-v2.cjs`, `node test-startup.cjs`, `node test-game.cjs`, `node test-reactions.cjs`, `node test-sound.cjs`, `node test-sharing.cjs`, `node test-analytics.cjs`, `node test-card-centering.cjs`.

자동 검사는 실제 모바일 터치·메신저 발송을 대신하지 않습니다. 배포 및 공개 브라우저 검증 상태는 `PROGRESS.md`에 기록합니다.

하단의 로고와 `© Bodyall`은 기존 공식 안내로 연결합니다. 인물 알아보기는 한국어 문서로 연결합니다. 삼국지연의를 현대적으로 해석한 오락이며 실제 진단이나 검증된 심리검사는 아닙니다.
