# 화타의 전생 진찰소

바디올한의원이 만든 삼국지 전생 성향 테스트. 기존 바디올 클리닉 게임 주소에서 제공하는 새 콘텐츠입니다.

공개 경로: https://wiki.body-all.co.kr/contents/bodyall-clinic/

## 플레이

한의사로 돌아온 화타에게 손목을 맡기고 열 문항에 답합니다. 답변 완료 후 화타가 들고 있던 거울로 확대되며 정면 초상화가 나타납니다. 일반 인물12종, 전부 ‘잘 모르겠어요’일 때의 특별한 말 결과, 성향 답변이 전혀 없을 때의 안개 낀 거울이 있습니다.

공유 카드1080×1350에는 인물, 별칭, 실제 선택한 답변에서 뽑은 분석 최대 두 문장, 바디올한의원 이름을 담습니다. 성별·몸 상태·불편한 부위·문항별 원문 답변은 공유하지 않습니다. 공유 API를 지원하지 않으면 이미지 저장과 링크 복사를 이용합니다.

## 파일

- `index.html` / `style.css`: 1인칭 진찰 장면과 반응형 화면.
- `data.js`: 질문10개, 인물12명, 작품 이야기와 출처, 성향 문구.
- `engine.js`: 결정적 매칭, 예외 처리, 공유 링크.
- `card.js`: 브라우저 canvas용 공유 카드 그리기. DOM에 의존하지 않는 그리기 함수.
- `app.js`: 질문 이동, 화타 모션·대사, 거울 공개, 공유·재시도.
- `assets/huata-*.webp`: 이번 버전의 그림5종. 기존 게임의 다른 그림은 사용하지 않습니다.
- `ARTWORK.json`: 이미지 생성·편집 프롬프트, 실제 크기, 배치 정보, 제작 자산 해시.
- `PLAN.md`: 원장님과 합의한 상세 기획안.
- `PROGRESS.md`: 완료 상태와 후속 작업을 위한 인수 기록.
- `test-game.cjs`: 일반 답변16,384조합, 특별 결과, 근거 문구, 공유 파라미터 검증.

## 검증과 실행

별도 빌드나 외부 패키지가 없는 정적 HTML/CSS/JavaScript입니다. 일반 정적 웹 서버 또는 GitHub Pages로 제공합니다. 검증: `node --check app.js`, `node --check card.js`, `node test-game.cjs`.

성별과 건강 관련 처음 세 답변은 일반 결과의 매칭이나 동점 해소에 사용하지 않습니다. 성향 일곱 문항과 대표 패턴의 일치 수로 정하고, 동점은 기획안의 우선순위·결정적 규칙으로 처리합니다. 결과의 실제 심리 타당성이나 바이럴 성과를 검증했다고 주장하지 않습니다.

자동 테스트는 브라우저에서의 실제 터치·다운로드·메신저 공유 시험을 대신하지 않습니다. 이 구현 작업에서는 브라우저 UI 테스트를 실행하지 않았습니다. 모든 이미지의 실제 로딩은 페이지 시작 시 확인하고, 실패하면 다시 불러오기 버튼을 제공합니다.

## 데이터와 소리

답변은 메모리에만 보관합니다. 서버 호출, 외부 분석 도구, 로그인, 쿠키, localStorage를 사용하지 않습니다. `bodyall:game-event` CustomEvent는 현재 브라우저 안에서만 발생하며 결과 ID 같은 비민감한 운영 정보만 담습니다. 이 이벤트는 수집 서버로 전송되지 않습니다.

첫 손목 맡기기 클릭에서 음악과 소리가 시작됩니다. 소리 버튼으로 끌 수 있고, 다시하기 후에도 선택이 유지됩니다. 동작 줄이기 설정을 따릅니다.

## 진료 연결

결과 하단의 바디올한의원 안내는 기존 공식 `https://wiki.body-all.co.kr/SART.html`로 연결합니다. 게임은 삼국지연의를 현대적으로 해석한 오락이며 실제 진단이나 치료 필요성을 판정하지 않습니다.


### 화타의 대화 반응

`reactions.js`가 선택한 답변에 맞는 짧은 대사·표정·동작을 정하고, `actor.js`가 눈 깜빡임과 일시적 자세 변화를 제어합니다. `REACTION_ARTWORK.json`에 4×2 표정 그림의 프레임 순서와 원본 좌표가 있습니다. 손과 거울을 고정한 채 상체만 움직이며, 선택 후 잠시 응답을 보여줍니다. `node test-reactions.cjs`로 반응 연결과 타이머 수명주기를 확인합니다.


### 음악과 목소리

첫 시작 클릭 후 `sound.js`가 1분 오리지널 곡 `assets/huata-courtyard.mp3`를 반복합니다. 소리 버튼은 음악·추임새·효과음을 함께 제어합니다. 추임새는 음·음음·어·아하·허허 5종의 고정 MP3를 재생합니다. 82세 한국인 할아버지의 음색을 지정해 Qwen3-TTS VoiceDesign 공개 모델을 로컬 CPU에서 실행했습니다. 기기 기본 음성 합성과 유료 생성 API는 사용하지 않습니다. 재생 시 생성 비용도 없습니다. 제작 코드·원본·음색 지침은 `audio-source/`와 `AUDIO.json`에 남겼습니다. 음악은 `audio-source/compose.py`의 직접 작곡·합성 출력이며 추가 API 호출이 없습니다.

`node test-sound.cjs`, `node test-startup.cjs`로 선택 반응/시작 흐름을 검사합니다. `test-card-centering.cjs`는 선택적 검증 도구 `@napi-rs/canvas`가 필요합니다.
