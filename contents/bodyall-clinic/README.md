# 화타의 전생 진찰소

Bodyall이 만든 삼국지 전생 성향 테스트. 제작자 표기는 로고와 `© Bodyall`로 통일하며 기존 게임 주소에서 제공합니다.

공개 경로: https://wiki.body-all.co.kr/contents/bodyall-clinic/

## 플레이

한의사로 돌아온 화타에게 손목을 맡기고 열 문항에 답합니다. 답변 완료 후 화타가 들고 있던 거울로 확대되며 정면 초상화가 나타납니다. 일반 인물12종, 전부 ‘잘 모르겠어요’일 때의 특별한 말 결과, 성향 답변이 전혀 없을 때의 안개 낀 거울이 있습니다.

공유 카드1080×1350에는 인물, 별칭, 실제 선택한 답변에서 뽑은 분석 최대 두 문장, 중앙정렬한 로고와 `© Bodyall`을 담습니다. 카드에 사이트 주소를 인쇄하지 않습니다. ‘내 결과 공유하기’는 인물·별칭·실제 분석·‘너는 누구였어?’ 문구와 결과 전용 링크를 보냅니다. 공유 API를 지원하지 않으면 같은 문구와 링크를 복사합니다. 이미지 저장도 유지합니다. 성별·몸 상태·불편한 부위·문항별 원문 답변은 공유하지 않습니다.

## 파일

- `index.html` / `style.css`: 1인칭 진찰 장면과 반응형 화면.
- `data.js`: 질문10개, 인물12명, 작품 이야기와 출처, 성향 문구.
- `engine.js`: 결정적 매칭, 예외 처리, 공유 링크.
- `card.js`: 브라우저 canvas용 공유 카드 그리기. DOM에 의존하지 않는 그리기 함수.
- `app.js`: 질문 이동, 화타 모션·대사, 거울 공개, 공유·재시도.
- `assets/huata-*.webp`: 이번 버전의 그림5종. 기존 게임의 다른 그림은 사용하지 않습니다.
- `ARTWORK.json`: 이미지 생성·편집 프롬프트, 실제 크기, 배치 정보, 제작 자산 해시.
- `PLAN.md`: 원장님과 합의한 상세 기획안.
- `PROGRESS.md`: 완료 상태와 후속 작업을 위한 인수 기록.
- `test-game.cjs`: 일반 답변16,384조합, 특별 결과, 근거 문구, 공유 파라미터 검증.
- `result/<id>/index.html`: 인물별 HTML 결과와 Open Graph/X 미리보기. 친구는 결과를 본 뒤 ‘그럼, 내 전생은?’으로 자기 테스트를 시작합니다.
- `shared-result.js` / `shared-result.css`: 공유받은 결과의 성향 두 문장 복원과 화면 스타일.
- `SHARING.json` / `scripts/build-share-pages.cjs`: 13종 공유 결과의 미리보기 정보와 기존 초상화 내보내기. 제작 도구만 `@napi-rs/canvas`를 사용하며 사이트 실행에는 패키지 설치가 필요 없습니다.
- `test-sharing.cjs`: 결과별 정적 메타데이터, 공유 문구·링크, 취소·실패·복사 대안, 친구의 결과 확인·새 참여 흐름 검증.

## 검증과 실행

별도 빌드나 외부 패키지가 없는 정적 HTML/CSS/JavaScript입니다. 일반 정적 웹 서버 또는 GitHub Pages로 제공합니다. 검증: `node --check app.js`, `node --check card.js`, `node test-game.cjs`.

성별과 건강 관련 처음 세 답변은 일반 결과의 매칭이나 동점 해소에 사용하지 않습니다. 성향 일곱 문항과 대표 패턴의 일치 수로 정하고, 동점은 기획안의 우선순위·결정적 규칙으로 처리합니다. 결과의 실제 심리 타당성이나 바이럴 성과를 검증했다고 주장하지 않습니다.

자동 테스트는 브라우저에서의 실제 터치·다운로드·메신저 공유 시험을 대신하지 않습니다. 2026-09-11 데스크톱 브라우저에서 시작→10문항→제갈량 결과→링크 복사→공유 페이지→새 참여와 GA4 실시간 수신을 확인했습니다. 실제 모바일·카카오톡 발송은 확인하지 않았습니다. 모든 이미지의 실제 로딩은 페이지 시작 시 확인하고, 실패하면 다시 불러오기 버튼을 제공합니다.

## 데이터와 소리

답변은 메모리에만 보관하며 외부에 보내지 않습니다. 게임 이용통계 연결은 `analytics-config.js`에서 관리합니다. 수집 설정을 활성화하고 이용자가 ‘통계 참여’를 선택한 경우에만 `analytics.js`가 허용된 진행·공유 이벤트를 Google Analytics 4에 전달합니다. 원문 답변·건강 정보·성별·분석 문장을 전달하지 않습니다. 통계 참여 여부는 localStorage에, 참여 시 게임 경로 전용 분석 식별자는 쿠키에 보관합니다. 설정이 꺼져 있거나 연결되지 않은 버전은 외부 수집을 하지 않습니다. 현재 연결 상태와 확인 절차는 `ANALYTICS.md`, 한글 CSV 요약과 배포 링크 도구는 `stats/`, 이용자 안내는 `privacy.html`에 있습니다.

공유 링크의 경로에는 결과 ID가, `#a=` 뒤에는 공개된 성향 문장 목록의 번호 최대 두 개만 들어갑니다. URL fragment는 결과 화면에서 문장을 복원하는 데 사용하며 요청 서버에는 보내지 않습니다. 링크 미리보기의 설명은 인물별 대표 성향, 직접 보내는 공유 문구와 친구가 연 결과 화면은 실제 받은 성향 분석입니다. 카카오톡 전용 SDK는 연결하지 않았으며 기기의 공유 창에서 카카오톡 등을 선택하거나 문구·링크를 붙여넣습니다. 실제 카카오톡 대화방 전송은 자동 검사하지 않았습니다.

첫 손목 맡기기 클릭에서 음악과 소리가 시작됩니다. 소리 버튼으로 끌 수 있고, 다시하기 후에도 선택이 유지됩니다. 동작 줄이기 설정을 따릅니다.

## 진료 연결

하단의 로고와 `© Bodyall`은 기존 공식 `https://wiki.body-all.co.kr/SART.html`로 연결합니다. 인물 알아보기는 한국어 위키백과의 해당 인물 문서로 연결합니다. 장비·조운·초선은 동음이의 문서를 피하도록 문서명을 지정했습니다. 게임은 삼국지연의를 현대적으로 해석한 오락이며 실제 진단이나 치료 필요성을 판정하지 않습니다.


### 화타의 대화 반응

`reactions.js`가 선택한 답변에 맞는 짧은 대사·표정·동작을 정하고, `actor.js`가 눈 깜빡임과 일시적 자세 변화를 제어합니다. `REACTION_ARTWORK.json`에 4×2 표정 그림의 프레임 순서와 원본 좌표가 있습니다. 손과 거울을 고정한 채 상체만 움직이며, 선택 후 잠시 응답을 보여줍니다. `node test-reactions.cjs`로 반응 연결과 타이머 수명주기를 확인합니다.


### 음악과 목소리

첫 시작 클릭 후 `sound.js`가 1분 오리지널 곡 `assets/huata-courtyard.mp3`를 반복합니다. 소리 버튼은 음악·추임새·효과음을 함께 제어합니다. 추임새는 원장님이 직접 듣고 음색을 승인한 샘플에서 음·아하·허허 3종을 잘라 만든 고정 MP3입니다. 새로 생성하지 않고 승인한 녹음의 음높이·속도·볼륨을 유지합니다. 아프거나 잘 모르겠다는 답에는 차분한 ‘음’을, 성향 답변에는 표정에 맞는 추임새를 재생합니다. 여러 후보가 있으면 연속 반복을 피하고, 차분한 후보가 하나뿐일 때는 답변마다 재생합니다.

승인 샘플은 Qwen3-TTS CustomVoice의 고정 화자 `Uncle_Fu`로 로컬 CPU에서 만들었습니다. 기기 기본 음성 합성과 유료 API를 사용하지 않으며 재생 시 생성 비용도 없습니다. 승인 원본·생성 정보·분할 코드는 `audio-source/approved-voice*`, `audio-source/prepare-approved-voice.py`, `AUDIO.json`에 있습니다. 이전 VoiceDesign 5종은 음색 문제로 거절되어 현재 재생 목록에서 제외했습니다. 음악은 `audio-source/compose.py`의 직접 작곡·합성 출력입니다.

`node test-sound.cjs`, `node test-startup.cjs`로 선택 반응/시작 흐름을 검사합니다. `test-card-centering.cjs`는 선택적 검증 도구 `@napi-rs/canvas`가 필요합니다.
