# 바디올한의원 〈화타의 전생 진찰소〉 기획안

작성일: 2026-09-11 · 상태: 제작을 위한 기획 초안

> 한의사로 돌아온 화타에게 손목을 맡긴다. 짧은 질문 열 개에 답하면, 화타가 든 거울에 내 삼국지 전생이 나타난다.

이번 콘텐츠의 중심은 **내가 누구로 나올지 궁금한 마음, 공개되는 순간의 즐거움, 친구와 결과를 비교하는 재미**다. 바디올한의원은 화타가 진찰하는 공간이자 이 경험을 만든 곳으로 기억되게 한다.

## 1. 이번 기획의 결정

| 항목 | 기획안 |
|---|---|
| 이름 | 화타의 전생 진찰소 |
| 첫 화면 제목 | 당신은 전생에 누구였을까요? |
| 보조 문구 | 화타가 봐주는 삼국지 전생 |
| 형식 | 1인칭 도트 그래픽 성향 테스트 |
| 분량 | 질문 10개, 약 60~90초를 목표로 설계. 실제 소요 시간은 시제품에서 확인 |
| 화자 | 현대의 한의사로 환생한 화타 |

| 첫 버전의 재미 | 질문을 빨리 넘기는 맛, 살아 있는 화타, 거울 공개, 친구와 비교 |

이 문서는 새 콘셉트의 별도 상세 기획안이다. 기존 〈딱 맞혀봐〉 기획과 구분한다. 이번 작업 범위는 기획이며, 기존 게임 수정·이미지 제작·배포는 포함하지 않았다.

## 2. 왜 한의원이 만들었는지 바로 이해되는 설정

설명해야 할 설정은 세 가지뿐이다. **앞의 사람은 화타, 손목을 맡긴 사람은 나, 거울에 나타날 사람은 내 전생**이다.

첫 화면에서 이를 장면과 두 줄로 보여준다.

> 화타: “난 전생에 화타였다네. 자네는 누구였을까?”
>
> 화타: “손목 좀 주게. 저 거울로 한번 보세.”

시작 버튼은 **‘손목 맡기기’**. 화타 이름 아래 작은 소개는 **‘한의사로 돌아온 화타’**로 한 번만 노출한다. 이후에는 ‘화타’만 표시한다.

현실의 한의원에서 전생을 진단한다는 광고 문구는 사용하지 않는다. 콘텐츠 하단에 **‘삼국지연의를 바탕으로 만든 재미용 테스트입니다.’**를 짧게 둔다. 이 안내를 긴 설명이나 시작 전 동의 화면으로 만들지는 않는다.

브랜드가 전달할 메시지는 **‘바디올한의원이 만든, 화타에게 받아보는 재미있는 전생 진찰’**이면 충분하다. 결과마다 척추나 추나 이야기를 붙이지 않는다. 진료 전문성을 설명할 공간은 별도의 한의원 안내로 둔다.

## 3. 한 장면을 끝까지 사용하는 화면

### 3.1 기본 구도

모바일 세로 화면을 기준으로 제작한다. 위에는 진찰 장면, 아래에는 질문과 선택지를 둔다. 데스크톱에서도 등장인물 사이의 거리와 시선은 같은 구도를 유지한다.

| 위치 | 보여줄 것 | 역할 |
|---|---|---|
| 배경 중앙 상단 | 첨부 로고의 금색 심벌 | 바디올의 공간이라는 시각적 기억 |
| 화면 중앙 | 현대 한의사 복장의 화타 | 유일한 진행자 |
| 화면 왼쪽 아래 | 내 왼손과 화타의 오른손 | 손목을 맡긴 1인칭 시점 |
| 화면 오른쪽 | 화타의 왼손에 들린 거울 | 끝까지 보고 싶은 대상 |
| 거울 안 | 검은 인물 실루엣 | 아직 공개되지 않은 전생 |
| 하단 패널 | 질문 한 문장, 답안 버튼, 1/10 | 읽기와 조작 |

화타의 **오른손은 화면 왼쪽에서 내 손목을 짚고, 왼손은 화면 오른쪽에서 거울을 든다.** 손과 팔이 겹치는 순서를 일관되게 유지한다. 거울 면은 화타가 아닌 플레이어를 향한다.

로고는 첨부 이미지의 금색 심벌만 사용한다. 아래의 한글과 영문 글자는 모두 제거하는 방향이다. 배경에는 별도의 ‘한의원’ 간판이나 글자를 넣지 않는다. 심벌이 화타의 머리에 완전히 가려지지 않도록 중앙 상단에 여백을 잡는다.

첫 화면의 작은 제작 표기와 결과·공유 카드에는 **바디올한의원**이라는 전체 이름을 사용한다. 배경 심벌만으로 처음 보는 사람이 상호를 알아볼 것이라고 가정하지 않는다.

### 3.2 그림의 분위기

- 따뜻한 목재, 차분한 크림색 벽, 금색 로고를 기본으로 한다.
- 화타는 흰 눈썹과 수염, 웃음기 있는 눈, 약간 능청스러운 표정의 노인이다.
- 익살은 표정과 대사에서 만든다. 진맥하는 손길과 진료 공간은 침착하고 정돈되어 있다.
- 옛 처방전·기괴한 약병·피·침 시술 장면을 장식으로 과하게 사용하지 않는다.
- 도트의 선명함과 인물의 표정이 함께 살아야 한다. 작은 네모 몇 개로 얼굴을 생략하지 않는다.
- 특정 삼국지 게임의 초상화·UI·능력치 표를 복사하지 않고, 같은 시대를 떠올리게 하는 자체 초상화를 만든다.
- 질문과 버튼 글자는 그림에 구워 넣지 않는다. 읽기 쉬운 한국어 본문 글꼴을 사용하고 장식용 도트 글꼴은 제목 등에 제한한다.

### 3.3 살아 있는 화타

| 동작 | 권장 연출 | 주의점 |
|---|---|---|
| 숨쉬기 | 3~5초 주기로 가슴·어깨·수염이 아주 작게 움직임 | 캐릭터 전체가 위아래로 튀지 않게 함 |
| 눈 깜박임 | 불규칙한 간격의 짧은 2~3프레임 | 모든 부위가 같은 주기로 반복되지 않게 함 |
| 답변 반응 | 눈썹을 들거나 고개를 조금 기울임 | 선택할 때마다 큰 리액션을 하지 않음 |
| 거울 확인 | 중후반에 눈과 고개가 거울 쪽으로 잠깐 이동 | 아직 특정 인물이라고 단정하지 않음 |
| 진맥 | 손가락 끝의 아주 작은 변화 | 내 손목과 화타 손의 접촉 위치 고정 |
| 거울 | 드문 빛의 흐름과 마지막의 미세한 떨림 | 선택할 때마다 다른 인물 얼굴을 미리 보여주지 않음 |

숨쉬기를 위해 화타 전체 이미지를 통째로 이동시키면 손목과 손이 떨어져 보인다. 머리·상체·진맥 손·거울과 잡은 손을 나눠 움직이고, 접촉 지점을 기준으로 변형한다. 이미지 제작 단계부터 레이어를 분리한다.

## 4. 질문 10개 — 실제 화면 문구

화타의 말투는 짧고 일관되게 유지한다. 답변은 사용자가 일상에서 하는 말로 쓴다. 삼국지 지식을 묻거나 인물을 직접 고르게 하지 않는다.

**모든 질문에 ‘잘 모르겠어요’를 제공한다.** 아래 A~E와 N은 구현용 구분이며 화면에는 보이지 않는다. 한 번에 하나만 선택하고, 선택 즉시 다음 질문으로 넘어간다. 이전 질문으로 돌아가 수정할 수 있다.

### Q1. “성별은 어떻게 되나?”

| 코드 | 답변 |
|---|---|
| A | 남성이에요 |
| B | 여성이에요 |
| C | 그 외예요 |
| N | 잘 모르겠어요 |

성별은 요청에 따라 포함하되 전생 인물을 제한하지 않는다. 누구나 초선이나 관우가 될 수 있다. 현재 성별로 성격 점수나 초상화를 바꾸지 않는다.

### Q2. “요즘 몸 상태는 어떤가?”

| 코드 | 답변 |
|---|---|
| A | 쉽게 지쳐요 |
| B | 움직일 기운은 넘쳐요 |
| C | 날마다 달라요 |
| D | 대체로 괜찮아요 |
| N | 잘 모르겠어요 |

### Q3. “자주 불편한 곳이 있나?”

| 코드 | 답변 |
|---|---|
| A | 목이나 어깨요 |
| B | 허리나 다리요 |
| C | 속이나 배요 |
| D | 머리나 눈이요 |
| E | 딱히 없어요 |
| N | 잘 모르겠어요 |

Q2와 Q3는 진찰 맥락과 화타의 짧은 반응에 사용한다. 특정 부위를 특정 인물·성격·질환으로 연결하지 않는다. ‘딱히 없어요’는 정상적인 답변이며 ‘잘 모르겠어요’와 별개다.

## 5. 결과 인물 12명

이 표의 별칭은 **삼국지 인물을 현대적으로 해석한 콘텐츠 문구**다. 실제 플레이어에게 붙이는 설명은 선택한 답변에서 별도로 뽑는다. 모든 인물의 도덕성을 평가하거나 누구의 인생이 더 낫다고 순위를 매기지 않는다.

| 인물 | 화면에 붙일 별칭 | 주요 구분 | 공개 순간 화타의 한마디 |
|---|---|---|---|
| 제갈량 | 머릿속에 지도가 펼쳐진 책사 | 깊은 생각, 직접 챙김, 계획 | “제갈량이었구만! 그 부채는 어디 두고 왔나?” |
| 조조 | 판을 읽고 먼저 움직이는 승부사 | 상황 판단, 위임, 실행 | “조조로군! 이 작은 방에서 천하를 논할 셈인가?” |
| 유비 | 사람을 모으는 군주 | 관계, 동행, 주변 의견 | “유비였구먼. 밖에서 두 아우가 기다리나?” |
| 관우 | 한 번 한 약속은 지키는 장수 | 원칙, 책임, 신뢰 | “관우로구먼! 수염부터 알아봤어야 했는데.” |
| 장비 | 속마음이 먼저 튀어나오는 호걸 | 빠른 반응, 행동, 솔직한 감정 | “장비였구만. 거울 너머로도 우렁차군!” |
| 조운 | 위기에서 더 선명해지는 해결사 | 침착함, 책임, 꾸준한 수행 | “조운이었군! 그 난리통에도 맡은 일은 해내던 자네.” |
| 손권 | 혼자보다 함께 강해지는 군주 | 위임, 의견 조율, 사람 선택 | “손권이었구만. 믿을 사람 보는 눈이 있었지.” |
| 주유 | 잘하는데, 더 잘하고 싶은 지휘관 | 실력, 인정, 승부욕 | “주유였군! 거울에도 대도독의 기품이 남았어.” |
| 사마의 | 마지막 수를 남겨두는 전략가 | 관찰, 기다림, 자기 속도 | “사마의였구만. 끝까지 기다릴 줄 알았지.” |
| 황충 | 실력으로 대답하는 노장 | 지속성, 원칙, 실력으로 인정받기 | “황충이었군! 아직 한창이라는 표정이구먼.” |
| 여포 | 말보다 실전이 빠른 무장 | 직접 해결, 즉시 행동, 자신감 | “여포였구만! 적토마는 밖에 세워뒀나?” |
| 초선 | 사람의 마음으로 판을 바꾸는 인물 | 타인의 반응, 관계, 상황 전환 | “초선이었군! 칼 없이도 판을 흔들던 자네.” |

삼국지를 잘 모르는 사람도 ‘책사·군주·장수’와 짧은 별칭으로 결과를 이해할 수 있어야 한다. 이름만 던지거나 생몰년·관직 설명을 먼저 내보내지 않는다. 황충은 실제 나이로, 초선은 성별이나 외모로 배정하지 않는다. 조조·여포 결과에 배신자·나쁜 환자 같은 낙인을 붙이지 않는다.

### 5.1 인물 해석의 작품 근거

## 6. 답변과 결과를 연결하는 규칙

### 6.1 기본 원칙

Q4~Q10의 일곱 답변으로 인물을 고른다. 아래 각 인물의 대표 답변과 일치하면 해당 인물에 1점을 준다. N은 모든 인물에 0점이다. 점수는 내부 계산에만 쓰며 사용자에게 성격 정확도나 백분율로 보여주지 않는다.

| 인물 | Q4 | Q5 | Q6 | Q7 | Q8 | Q9 | Q10 |
|---|---|---|---|---|---|---|---|
| 제갈량 | A | A | A | A | A | A | A |
| 조조 | A | A | B | B | A | A | D |
| 유비 | C | C | C | C | C | C | C |
| 관우 | A | D | D | D | B | C | A |
| 장비 | B | B | C | B | B | D | B |
| 조운 | D | D | D | D | D | C | A |
| 손권 | C | D | B | C | C | C | C |
| 주유 | A | A | A | A | B | B | B |
| 사마의 | D | D | A | A | D | A | D |
| 황충 | B | D | D | D | B | B | B |
| 여포 | B | B | A | B | B | B | B |
| 초선 | C | C | C | C | A | D | C |

이 표는 제작 가능한 최초 매칭 초안이다. 예컨대 제갈량과 조조는 둘 다 생각이 많을 수 있지만 직접 챙기는지·맡기는지·언제 움직이는지로 갈린다. 관우와 조운은 모두 책임감이 강하지만 밀어붙임과 기다림에서 구분한다. 유비와 손권은 관계를 맺는 방식과 위임에서 구분한다.

### 6.2 동점과 예외

1. **열 문항 모두 N이면 말 결과가 최우선**이다. 성별·몸 상태·불편 부위 문항도 이 조건에 포함한다.
2. 일반 결과는 Q4~Q10 점수 합계가 가장 높은 인물이다.
3. 동점이면 Q6 → Q7 → Q9 → Q8 → Q4 → Q5 → Q10 순서로 대표 답변 일치 여부를 비교한다. 합산 점수가 같을 때만 이 우선순위를 쓴다.
4. 그래도 같으면 동점 인물의 이름을 유니코드 오름차순으로 정렬한다. Q4~Q10의 답변을 N=0, A=1, B=2, C=3, D=4로 바꿔 5진 정수를 만들고, 이를 동점 인원수로 나눈 나머지 위치의 인물을 고른다. 같은 답변이면 같은 결과다.
5. Q4~Q10을 전부 N으로 골랐지만 열 문항 모두 N은 아닌 경우에는 **‘안개 낀 거울’** 화면으로 끝난다. “전생이 아직 흐릿하구먼. 성격 이야기 세 가지만 더 들려주겠나?”와 ‘답변 보태기’를 제공한다. 이 버튼은 Q6·Q7·Q9를 수정하는 화면으로 돌아간다. 새 질문을 추가하거나 아무 근거 없이 특정 인물을 확정하지 않는다.
6. Q4~Q10에 유효 답변이 1~2개뿐이면 ‘희미하게 보이는 전생’이라는 작은 표시와 함께 결과를 보여준다. 근거도 실제로 일치한 만큼만 표시한다.

Q1~Q3의 응답은 일반 인물 선택과 동점 해소에 사용하지 않는다. 몸이 불편하다는 답변을 바꾸었다고 전생이 달라지지 않는다. 말 결과는 무지나 건강 상태에 대한 평가가 아니라 **열 번의 동일한 선택에 대한 숨겨진 농담**이다.

### 6.3 결과 설명을 만드는 방식

인물을 고른 뒤, 그 인물과 일치한 실제 답변 중 두 개를 Q6 → Q7 → Q9 → Q8 → Q4 → Q5 → Q10 순서로 골라 표시한다. 일치가 하나뿐이면 한 개만 쓴다. 선택하지 않은 답변을 근거로 지어내지 않는다.

선택지 문구를 그대로 되풀이하는 대신 의미를 유지해 짧게 바꾼다. 아래 대응표 전체를 사용한다.

| 문항 | A를 골랐을 때 | B를 골랐을 때 | C를 골랐을 때 | D를 골랐을 때 |
|---|---|---|---|---|
| Q4 | 쉬면서도 다음 일을 생각함 | 가만히 있기보다 움직이는 편 | 쉬다가도 사람을 챙김 | 혼자 조용히 보내는 시간을 좋아함 |
| Q5 | 스트레스를 받으면 생각이 많아짐 | 스트레스를 받으면 반응이 빨라짐 | 다른 사람의 반응을 신경 씀 | 혼자 생각을 정리하는 편 |
| Q6 | 직접 챙겨야 마음이 놓임 | 믿는 사람에게 맡길 줄 앎 | 함께하면서 힘을 보탬 | 맡은 일은 묵묵히 끝냄 |
| Q7 | 충분히 따져보고 결정함 | 마음이 서면 바로 움직임 | 주변 의견을 듣고 결정함 | 익숙한 원칙을 기준으로 삼음 |
| Q8 | 일이 틀어지면 새 방법을 찾음 | 일단 부딪치며 길을 찾음 | 사람들과 맞추며 풀어감 | 서두르지 않고 때를 기다림 |
| Q9 | 문제를 해결했다는 말이 힘이 됨 | 실력을 인정받을 때 힘이 남 | 든든한 사람이라는 말이 힘이 됨 | 마음을 이해받을 때 힘이 남 |
| Q10 | 하던 일을 정리해야 쉬기 편함 | 조금 더 해보고 싶은 마음이 큼 | 부탁한 뒤 쉬는 편 | 쉴 때를 받아들일 줄 앎 |

### 6.4 제갈량 결과 예시

다음 예시는 Q4~Q10에서 A를 고른 경우다.

> **당신의 전생은 제갈량**
>
> 머릿속에 지도가 펼쳐진 책사
>
> 직접 챙겨야 마음이 놓임 · 충분히 따져보고 결정함
>
> 화타: “제갈량이었구만! 그 부채는 어디 두고 왔나?”
>
> **친구에게 공유하기**　**다시 해보기**
>
> 바디올한의원이 만든 〈화타의 전생 진찰소〉

‘인물 이야기’를 펼치면 제갈량이 세세한 일까지 직접 챙기던 작품 속 장면을 두 문장 정도로 보여준다. 결과 첫 화면에는 장문의 성격 분석, 질환명, 체질명, 치료 권유를 넣지 않는다.

### 6.5 기획 단계에서 확인한 것

N을 제외한 일곱 문항의 모든 조합 16,384개를 위 규칙으로 계산했다. 12명 모두 도달 가능하고, 각 인물의 대표 답변 조합은 해당 인물로 나왔다. 이 균등 조합 실험에서 인물별 비중은 약 6.4~10.7%였고, 최종 인물과 일치하는 답변은 최소 두 개였다.

이는 **매칭 구조가 막혀 있지 않은지 확인한 계산**이다. 실제 이용자는 모든 선택지를 같은 확률로 고르지 않으므로, 실제 결과 분포·성격 타당성·재미·바이럴 성과를 뜻하지 않는다. 답변 문구를 바꾸면 인물별 의미와 매칭표를 함께 재검토한다.

## 7. 화타의 혼잣말과 답변 반응

질문도 화타가 하고, 혼잣말도 화타가 한다. 새로운 화자나 해설자를 추가하지 않는다. 질문은 고정된 하단 패널에, 혼잣말은 얼굴 옆 작은 말풍선에 표시한다.

선택지를 누르기 위해 혼잣말이 끝날 때까지 기다릴 필요가 없다. 전체 플레이에서 혼잣말은 최대 네 번 정도만 노출한다. 빠르게 답하면 지나간 대사를 밀려서 재생하지 않는다.

| 시점 | 대사 후보 | 표정·동작 |
|---|---|---|
| Q2 응답 뒤 | “음… 어디 보자.” 또는 아래 상태 반응 하나 | 손목을 보며 짧게 눈 깜박임 |
| Q4 응답 뒤 | “전생에도 이런 버릇이 있었을까…” | 눈썹을 살짝 듦 |
| Q7 응답 뒤 | “어디서 본 듯한데…” | 거울을 잠깐 바라봄 |
| Q9 응답 뒤 | “이제 조금 보이는군.” | 거울 표면에 아주 작은 빛 |
| 마지막 응답 뒤 | “자, 직접 보게.” | 거울을 플레이어 쪽으로 조금 기울임 |

Q2에서 ‘쉽게 지쳐요’라면 “요즘 쉽게 지치는구먼.”, ‘움직일 기운은 넘쳐요’라면 “움직일 기운은 충분하구먼.”, ‘날마다 달라요’라면 “날마다 좀 다르구먼.”, ‘대체로 괜찮아요’라면 “대체로 괜찮다니 다행이네.” 중 하나로 받아준다. N이면 일반 혼잣말을 쓴다. 이것은 답변을 들었다는 반응이며 진단이나 치료 효과 설명이 아니다.

Q3의 부위 답변은 Q2 반응을 쓰지 않은 경우에 한해 “목이나 어깨 쪽이 불편하구먼.” 같은 짧은 수용 대사로 활용할 수 있다. 두 반응을 연달아 추가하지 않는다. 다른 부위와의 인과관계를 덧붙이지 않는다.

‘참고로 난 전생에 화타였다네’는 시작 대사에 반영했으므로 진찰 중 반복하지 않는다. 거울 공개 전에는 인물 이름이나 동물 결과를 암시하지 않는다.

## 8. 거울 공개 — 이 콘텐츠에서 가장 공들일 장면

화타가 들고 있던 **바로 그 거울**로 카메라가 다가가야 한다. 화면 중앙에 별도의 결과 카드를 갑자기 띄우는 전환은 사용하지 않는다.

| 마지막 답변 이후 | 화면 | 소리·말 |
|---|---|---|
| 0.00~0.25초 | 질문 패널이 사라지고 화타의 시선이 거울로 이동 | “자, 직접 보게.” |
| 0.25~1.05초 | 실제 거울 위치를 중심으로 확대, 배경은 점차 어두워짐 | 짧게 고조되는 소리, 소리를 켠 경우에만 |
| 1.05~1.65초 | 거울 안으로 금색 물결이 지나가고 실루엣 경계가 흔들림 | 맑은 공명음 |
| 1.65~2.05초 | 검은 얼굴이 해당 인물의 정면 얼굴로 바뀜 | 짧은 공개 효과음 |
| 2.05~2.60초 | 인물 이름과 화타의 한마디, 결과 조작부가 들어옴 | 결과 한마디는 문자로 표시 |

시간은 연출 초안이다. 실제 체감에 맞춰 조정하되 공개 전 강제 대기 시간을 길게 늘리지 않는다. 소리는 기본 꺼짐이며 켜지 않아도 정보와 타이밍을 이해할 수 있어야 한다.

### 거울 속 얼굴의 기준

- 플레이어가 자기 전생의 얼굴을 마주 보는 **정면 시선**이다.
- 다른 곳을 보는 3/4 각도 장수 카드로 대체하지 않는다.
- 얼굴은 거울 안쪽에 마스킹하고 프레임과 손은 바깥 레이어에 둔다.
- 모자·깃털·수염·갑옷 일부로 인물의 차이를 주되, 얼굴과 눈을 먼저 알아볼 수 있어야 한다.
- 12명 모두 눈높이·얼굴 크기·반사광 위치를 통일한다.
- 결과가 나오는 순간에는 거울의 반사광을 줄여 얼굴을 가리지 않는다.
- 과도한 화면 흔들림이나 반복적인 흰색 섬광 대신 물결·빛·윤곽 변화로 임팩트를 만든다.
- 동작 줄이기 설정에서는 확대·흔들림을 짧은 화면 전환으로 대체한다.

결과 공개가 끝나면 거울 초상화와 이름, 별칭, 근거 두 줄, 공유·재도전이 한 화면에서 읽히도록 정리한다. 작은 화면에서는 ‘인물 이야기’와 한의원 안내가 아래로 내려가도 핵심 버튼은 쉽게 닿아야 한다.

## 9. 숨겨진 결과 — 하후돈의 이름 모를 말

발동 조건은 **Q1~Q10을 모두 ‘잘 모르겠어요’로 완료**하는 것이다. 중간에 답변을 바꿨다면 최종 답변만 기준으로 삼는다. 조건을 시작 화면이나 일반 결과에서 먼저 알려주지 않는다.

공개 직전까지 일반 결과와 동일하게 충분히 진지하게 연출한다. 거울에서 사람 대신 정면의 말 얼굴이 나타나고, 약 0.4초의 짧은 정적 뒤 화타의 말이 나온다.

> “……자네, 사람이 아니었구만.”
>
> “하후돈이 타고 다니던 말일세.”
>
> “이름은 나도 모르겠네.”

결과 카드 문구:

> **하후돈의 이름 모를 말**
>
> 주인 이름은 아는데, 내 이름은 모른다.
>
> 무슨 질문이 와도 대답은 한결같아요.
> 정체는 흐려도 일관성은 확실해요.

말은 우스꽝스럽되 귀엽게 그린다. 눈은 양쪽 모두 정상이고, 말에게 하후돈의 외형 특징을 잘못 옮기지 않는다. 말 결과에 낮은 지능이나 낮은 인간적 가치를 뜻하는 능력치를 붙이지 않는다.

**‘하후돈의 이름 모를 말’은 이 콘텐츠가 만든 개그 설정이다.** 특정 말의 실제 기록을 발견했다는 뜻이 아니다. 펼쳐보는 인물 이야기에는 ‘이 결과는 테스트를 위해 만든 특별 설정입니다.’라고 쓴다.

양송·황호는 첫 버전에서 제외한다. 설명 없이 말 얼굴만 봐도 반전을 이해할 수 있는 쪽을 우선한다. 일반 답변을 한두 번 모르겠다고 했다는 이유로 개그 결과에 보내지 않는다.

## 10. 결과 공유와 바디올한의원 연결

### 10.1 결과 화면의 순서

1. 거울 속 얼굴과 인물 이름.
2. 짧은 별칭과 실제 답변 근거 최대 두 개.
3. 화타의 한마디.
4. 큰 ‘친구에게 공유하기’, 보조 ‘다시 해보기’.
5. 접힌 ‘인물 이야기’와 작은 ‘바디올한의원 알아보기’.

별도의 예약 팝업이나 정보 입력으로 결과를 가리지 않는다. 건강 문진 결과처럼 보이는 상세 보고서도 만들지 않는다.

### 10.2 공유 카드

권장 출력은 세로 1080×1350 PNG다. 휴대전화 화면에서 얼굴과 인물 이름이 먼저 보이게 구성한다.

| 카드 영역 | 내용 |
|---|---|
| 상단 | 화타의 전생 진찰소 |
| 중앙 | 거울 프레임과 인물 얼굴 |
| 큰 제목 | 나는 전생에 제갈량 |
| 한 줄 | 머릿속에 지도가 펼쳐진 책사 |
| 간단 분석 | 실제 답변에서 뽑은 성향 두 가지를 짧은 두 문장으로 표시 |
| 작은 초대 | 너는 누구였을까? |
| 하단 | 금색 심벌 + 바디올한의원 |

공유 카드는 **누가 나왔는지와 어떤 점이 나를 닮았는지**를 함께 전달한다. 별칭 아래에 간단한 분석 두 줄을 반드시 배치한다. Q4~Q10에서 최종 인물과 일치한 실제 답변을 최대 두 개 뽑아, 6.3절의 대응표를 자연스러운 문장으로 바꾼다. 인물만 같다고 모든 사람에게 동일한 분석을 붙이지 않는다. 근거가 하나뿐이면 한 문장만 사용한다.

제갈량 공유 카드 예시 — Q6=A, Q7=A가 근거로 선택된 경우:

> **나는 전생에 제갈량**
>
> 머릿속에 지도가 펼쳐진 책사
>
> 직접 챙겨야 마음이 놓여요.
> 충분히 따져본 뒤 결정을 내려요.
>
> 너는 누구였을까?
>
> **바디올한의원 · 화타의 전생 진찰소**

분석은 두 줄, 합계 약 35~55자를 목표로 하고 실제 카드 너비에 맞춘다. ‘계획력 97점’ 같은 임의 수치 대신 친구가 읽고 알아볼 만한 생활 성향을 쓴다. 말 결과에도 9절의 짧은 개그 분석을 넣는다.

공유 카드에는 **성별, 피로 상태, 불편한 부위, 문항별 원문 응답은 넣지 않는다.** 성향 분석만 결과 내용으로 공유한다. 개인화된 분석은 공유·저장 이미지에 담고, 링크에는 원문 답변을 싣지 않는다. 링크만 열었을 때는 친구의 인물 이름만 소개한다. 메신저 링크 미리보기까지 개인화된 이미지로 바뀌는 기능은 기본 공유 이미지 기능과 구분해 제작 시 지원 여부를 확인한다.

공유 문구 초안:

> 나 전생에 제갈량이었대ㅋㅋ 너는 누구냐
>
> 화타의 전생 진찰소 · 바디올한의원

말 결과의 공유 문구 초안:

> 너는 뭐 나왔냐. 나는 말 나옴ㅋㅋ
>
> 화타의 전생 진찰소 · 바디올한의원

문구는 복사 후 고칠 수 있게 한다. 지원되는 환경에서는 이미지와 링크를 공유하고, 그렇지 않으면 ‘이미지 저장’·‘링크 복사’를 제공한다. 실제 지원 여부는 제작 단계에서 기기별로 확인한다.

### 10.3 친구가 들어왔을 때

공유 링크에 인물 식별자가 들어가면 첫 화면에 **‘친구의 전생은 제갈량. 당신은?’**처럼 짧게 표시할 수 있다. 새 방문자는 자기 답변으로 테스트를 시작하며, 친구의 결과를 그대로 받지 않는다.

임의의 궁합 수치·친구 점수·전체 순위를 추가하지 않는다. ‘나는 제갈량인데 너는 장비네’라는 비교 자체를 먼저 살린다. 숨겨진 결과의 실제 획득률이 없을 때 ‘0.1% 희귀’ 같은 문구를 만들지 않는다.

### 10.4 한의원 안내

결과 하단의 ‘바디올한의원 알아보기’에서 위치·진료 안내로 이동한다. 이 지점부터는 실제 한의원 정보라는 것을 분명히 구분한다. 링크와 소개 문구는 제작 시 공식 정보를 확인해 연결한다.

이 콘텐츠의 첫 성과는 참여와 상호 기억이다. 내원 효과는 지역 내 유입과 실제 문의·방문을 따로 확인해야 한다. 삼국지 콘텐츠가 널리 퍼진다는 이유만으로 내원이 늘었다고 결론 내리지 않는다.

## 11. 제작을 위한 자산 목록과 동작 범위

### 11.1 그림 자산

| 자산 | 수량·상태 | 제작 기준 |
|---|---|---|
| 한의원 배경 | 기본 1장 | 중앙 상단 금색 심벌, 별도 간판 글자 없음 |
| 화타 기본 몸·얼굴 | 기준 캐릭터 1종 | 동일한 옷·표정 계열과 조명 |
| 화타 표정·동작 | 눈 깜박임, 관찰, 미소, 의외라는 표정, 거울 보기 | 표정별 별개 인물이 되지 않게 함 |
| 진맥 손·내 손목 | 분리 레이어 | 접촉 부위가 고정되는 구조 |
| 거울과 잡은 손 | 분리 레이어 | 거울 내부만 별도 교체·마스킹 가능 |
| 거울 실루엣·빛 | 각 1세트 | 결과 공개 전에는 동일한 실루엣 |
| 일반 결과 초상화 | 12종 | 플레이어를 보는 정면 얼굴, 같은 프레임 기준 |
| 말 초상화 | 1종 | 같은 거울에 들어가는 정면 말 얼굴 |
| 안개 낀 거울 | 기존 거울 효과 재사용 | 인물 실루엣을 밝히지 않은 상태 |
| 브랜드 심벌 | 첨부 원본에서 정리 | 심벌 형태·색 비례 유지, 하단 한글·영문 제거 |

모든 자산은 동일한 도트 밀도·명암·윤곽선 규칙을 사용한다. 최초 화타 장면으로 스타일을 확정한 뒤 나머지 인물 초상화를 맞춘다. 거울 확대를 견딜 수 있는 원본 크기로 제작한다.

### 11.2 제작 동작

- 첫 화면, 열 문항, 공개 연출, 일반 결과 12종, 말 결과, 안개 낀 거울을 구현한다.
- 질문 응답으로 내부 결과를 계산한다. 실시간 AI 진단이나 외부 AI 호출은 필요하지 않다.
- 선택지는 한 문항씩 보여주며 이중 탭으로 질문이 건너뛰어지지 않게 한다.
- ‘이전’으로 바꾼 답변은 최종 결과와 말 조건에 모두 반영한다.
- 말풍선·효과음·애니메이션이 선택지 조작을 막지 않게 한다.
- 모바일에서 선택지를 최소 44px 높이로 만들고, 선택지가 많은 Q3는 패널 내부에서 필요 시 스크롤할 수 있게 한다.
- 결과 공유, 이미지 저장, 링크 복사, 다시 하기를 제공한다.
- 음소거, 동작 줄이기, 키보드 조작과 읽기 가능한 버튼 이름을 갖춘다.
- 답변은 브라우저 세션에서 계산하고, 성별·몸 상태·불편 부위를 외부로 전송하거나 분석 이벤트·공유 주소에 넣지 않는다.
- 공개 링크에 담는 정보는 버전·결과 인물·공유 유입 표시 정도로 제한한다.

### 11.3 제작 순서

1. 화타·손목·거울이 함께 있는 첫 장면과 제갈량·말 공개 장면을 만든다. 질문 두 개만 연결해 시점과 공개 연출부터 확인한다.
2. 짧은 사용자 확인으로 화자·내 역할·거울의 의미와 공개 순간의 반응을 본다.
3. 열 문항과 전체 매칭, 나머지 열한 명의 초상화, 결과 문구를 완성한다.
4. 공유 카드와 친구 유입, 한의원 안내를 연결한다.
5. 질문 완료·예외 답변·공유·모바일 사용을 확인한 뒤 공개한다.

먼저 완성할 부분은 화타의 매력과 거울 공개다. 그 장면을 보고도 결과가 궁금하지 않다면 인물 수부터 늘리지 않고 장면·제목·대사부터 조정한다.

## 12. 공개 전에 확인할 기준

### 12.1 재미와 이해

삼국지를 잘 아는 사람과 잘 모르는 사람을 섞어 10~15명 정도에게 시제품을 보여주는 소규모 확인을 제안한다. 이 인원은 문제를 찾기 위한 규모이며, 대중의 반응을 통계적으로 대표한다는 뜻은 아니다.

| 확인할 것 | 방법 | 수정 신호 |
|---|---|---|
| 역할 이해 | 첫 화면만 보고 앞의 사람·내 역할·거울의 의미를 말해달라고 함 | 한의사가 플레이어라고 오해하거나 거울의 목적을 모름 |
| 계속할 이유 | 질문 중 어디서 나가고 싶었는지 관찰 | 질문을 읽기도 전에 설명이 길다고 느끼거나 거울을 신경 쓰지 않음 |
| 결과 납득 | “왜 이 인물이 나왔다고 생각하세요?” | 답변 근거를 보고도 연결이 되지 않음 |
| 공개 효과 | 제갈량과 말 공개 장면의 반응 확인 | 얼굴을 못 알아보거나 연출이 길다고 느낄 때 |
| 친구와 비교 | 결과를 본 뒤 실제로 누구의 결과가 궁금한지 물음 | 인물만 확인하고 더 할 말이 없음 |
| 상호 기억 | 잠시 뒤 만든 곳 이름을 물음 | 화타만 기억하고 바디올한의원은 기억하지 못함 |

칭찬이나 ‘공유할 것 같다’는 응답만으로 성공을 판단하지 않는다. 실제 완료, 재시도, 공유된 링크를 통한 새 참여를 구분해서 본다.

### 12.2 제작 단계의 필수 확인

- 인물 12명 모두 도달 가능하고, 대표 답변을 넣으면 의도한 인물이 나오는가.
- 열 번 N만 말 결과가 되는가. ‘딱히 없어요’를 N으로 잘못 취급하지 않는가.
- 성격 문항 전부 N, 일부 N, 답변 수정, 뒤로 가기가 자연스럽게 처리되는가.
- 결과 설명에 실제 선택하지 않은 답변이나 증상 해석이 섞이지 않는가.
- 손목과 손이 애니메이션 중 떨어지지 않는가. 확대가 실제 거울에서 시작하는가.
- 거울 얼굴이 정면으로 보이며, 이름·근거·공유 버튼을 작은 화면에서도 읽을 수 있는가.
- 공유 이미지에 별칭과 실제 답변에 맞는 짧은 분석이 함께 읽히는가. 상호가 잘리거나 분석이 너무 작아지지 않는가.
- 성별·몸 상태·불편 부위·문항별 원문 응답이 공유 주소·이미지·분석 이벤트에 포함되지 않는가.
- 공유 기능을 사용할 수 없는 환경에서 저장과 복사가 동작하는가.

공개 후에는 시작 수, 완료 수, 재시도, 공유 동작, 공유 링크를 통한 새 시작, 한의원 안내 클릭을 각각 본다. 공유 버튼 클릭은 실제 공유 완료와 구분한다. 분석 도구를 붙이는 단계에서도 건강·성별 답변은 수집하지 않는다.

## 13. 이번 버전에서 지킬 중심

**화타는 읽기 귀찮은 설명자가 아니라, 내 전생을 궁금하게 만드는 인물이다. 질문은 짧아야 하고, 결과는 내가 고른 답변과 이어져야 하며, 거울 속 얼굴이 나타나는 순간이 가장 재미있어야 한다.**

바디올한의원은 시작 장면의 공간, 결과의 제작자 이름, 친구에게 넘어가는 카드에 함께 남는다. 이 관계를 먼저 완성한 뒤 실제 반응을 보고 다음 콘텐츠나 확장을 결정한다.
